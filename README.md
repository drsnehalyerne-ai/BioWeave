# BioWeave

### Weaving biological networks into therapeutic insights

BioWeave is an open systems biology platform designed to integrate:

- Transcriptomics
- Microbiome data
- Molecular pathways
- Protein interaction networks
- Target discovery
- Network medicine

## Current Focus

- Oral Leukoplakia
- Oral Submucous Fibrosis
- Oral Squamous Cell Carcinoma

## First Project

Deciphering Microbiome–Host Signaling Networks Driving Malignant Transformation of Oral Leukoplakia
